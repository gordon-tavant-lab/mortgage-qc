Mortgage QA/QC Engine — How It Actually Runs

From a rulebook and a stack of paperwork to a pass/fail answer

Four stages, start to finish. Two of them happen once and get saved for reuse — the other two happen fast, every time you check a loan.

Think of it like grading homework with a checklist. Stage 1 is writing the checklist. Stage 2 is reading the student's paperwork so you know the actual answers. Stage 3 is going down the checklist, question by question. Stage 4 is where you file the graded results.

Why two answer files? One runs just the 27 proven checks. The other runs both the proven checks and the giant 8,399-check list side by side, so you can see where they agree. The proven-checks file gets updated the moment a check changes; the side-by-side file only updates when someone re-runs that comparison — so the two can briefly show different numbers if one was refreshed and the other wasn't.
